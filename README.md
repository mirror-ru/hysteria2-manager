# Hysteria 2 Manager

Bash-скрипт для установки и управления сервером Hysteria 2 на Linux

## Установка

Требуются `root` и `curl`:

```bash
curl -fsSLo hysteria-manager.sh https://raw.githubusercontent.com/mirror-ru/hysteria2-manager/main/hysteria-manager.sh && bash hysteria-manager.sh
```

Повторный запуск:

```bash
bash hysteria-manager.sh
```

## Возможности

- установка сервера одной командой
- добавление и удаление клиентов через меню
- отдельный логин и пароль для каждого клиента
- готовые конфигурации, ссылки и QR-коды для подключения
- BBR включён автоматически
- Salamander включён по умолчанию для дополнительной маскировки трафика
- port hopping для сетей с нестабильным или блокируемым UDP
- сертификат Let's Encrypt или самоподписанный сертификат
- обновление Hysteria без ручной настройки
- изменение параметров сервера без переустановки
- удаление Hysteria через меню

## Меню

```text
1   Добавить клиента
2   Список клиентов / QR
3   Удалить клиента
4   Настройки сервера
5   Обновить ядро Hysteria
7   Удалить Hysteria
99  Обновить скрипт
0   Выход
```

## Проверка

Локальные регрессионные тесты:

```bash
bash tests/regression.sh
```

Тесты не заменяют проверку на реальном Linux-сервере: systemd, firewall и ACME в них не запускаются.
